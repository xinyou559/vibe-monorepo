# 依赖漏洞修复

## 背景
新建的小程序模板中，依赖链里存在诸多高危及中危的 `npm` 漏洞（如 `vue-i18n` 原型链污染、`esbuild` 等组件的网络安全风险）。为保障基础安全，需要将高危及以上漏洞修复，同时不破坏 uni-app 固化的核心版本。

## 目标
1. 将 `apps/miniapp` 下的 `High` 及 `Critical` 级别漏洞清零。
2. 保证 uni-app 小程序项目正常编译和运行。
3. 新增高危漏洞拦截测试，防止后续再引入。

## 验收标准
- [x] 运行 `npm run test:audit`（限制为高危）返回 0（通过）。
- [x] 运行 `npm run build:h5` 能正常通过且不报错。
