# Vibe Admin - 活力珊瑚橙 (Coral & Midnight) UI 优化原型设计

根据 `frontend-skill` 原则（单一强调色、克制排版、线框布局），我们将原有死板的黑白方案升级为 **“活力珊瑚橙”** 方案。以下是设计规格说明：

## 1. 色彩系统 (Color Palette)

- **主强调色 (Accent Color)**: `#FF6B4A` (活力珊瑚橙)
  - *用途*：主按钮、状态激活点、导航选中状态的高亮、核心数据正向变动。
- **主强调色悬停 (Accent Hover)**: `#E65A3D` (深珊瑚色)
  - *用途*：按钮 Hover 状态。
- **侧边栏背景 (Sidebar Background)**: `#1A1B26` (午夜蓝灰)
  - *用途*：侧边栏深色背景，比纯黑 `#000000` 更具呼吸感和高级感。
- **侧边栏选中/悬停 (Sidebar Hover)**: `#2A2C3D` (浅午夜蓝)
  - *用途*：导航项悬停时的微弱反差。
- **背景色 (Canvas & Surface)**: `#F7F7F9` (工作区背景) / `#FFFFFF` (核心内容区背景)
- **字体颜色 (Typography)**: 
  - 主标题：`#111111`
  - 次级文本：`#666666`
  - 弱化文本：`#999999`
  - 深色背景上的文本：`#FFFFFF` (配合 80% 和 50% 透明度构建层级)

## 2. 界面元素优化 (Component Updates)

### 侧边栏 (Sidebar)
- **品牌 Logo**: 珊瑚橙背景 `#FF6B4A` + 白色字母 "V"。
- **导航项**: 
  - 默认状态：文本透明度 60%，图标透明度 40%。
  - 选中状态 (`router-link-active`)：文字变为 100% 白色，左侧出现一个 `3px` 宽的珊瑚橙色指示条（Indicator），取代原有整个背景的高亮，显得更克制。

### 按钮 (Buttons)
- **Primary Action (如“新增服务”、“保存配置”)**:
  - 背景色：`#FF6B4A`，无边框，文字白色。
  - Hover：`#E65A3D`，伴随细微的 `transform: translateY(-1px)` 和轻微阴影，提升交互手感。
- **Secondary/Ghost Action (如“取消”、“配置”)**:
  - 保持全透明，边框 `#EAEAEA`，Hover 时边框变为 `#FF6B4A`，文字颜色变为 `#FF6B4A`。

### 状态标签 (Status Badges)
- **营业中 / 已完成 (Active/Completed)**: 
  - 取消大面积绿色背景。采用透明背景 + 珊瑚橙色圆点 (`#FF6B4A`) + 珊瑚橙色文字。
- **已下架 / 待支付 (Inactive/Init)**:
  - 浅灰色圆点 (`#CCCCCC`) + 灰色文字 (`#999999`)。

### 数据展示 (Data Tables)
- **金额高亮**: `+` 的金额和提成比例不再使用原谅绿，而是统一使用珊瑚橙 `#FF6B4A`，与系统主色调保持一致，传达“入账”的喜悦感。
- **Hover 效果**: 表格行 Hover 时，背景色微变，同时最右侧的操作按钮透明度从 `0` 变为 `1`（减少全局按钮的视觉噪音）。

## 3. 动效设计 (Motion Thesis)
- **侧滑抽屉 (Drawer)**: 保持 `cubic-bezier(0.16, 1, 0.3, 1)` 的顺滑入场。
- **按钮反馈**: 点击时增加 `scale(0.98)` 的微动效。
